# UIUX-CONVERGE-0 / P1 — Common grammar and local-owner convergence

## Classification

This is a **runtime-semantic implementation pass inside the canonical `UIUX-CONVERGE-0` slice**. It is not a new serial slice and it does not declare `UIUX-CONVERGE-0` complete.

Observed base: `main@c7619e18b260bc23a5aa968086e312570723f8f0` (merge of PR #143).

## End-user target

ICTC should behave as one professional workbench rather than a set of historically layered surfaces. The first plane is intentionally minimal: identity, current attention/work, material state/owner, the next action and the material claim boundary. Repeated records use rows/lists by default. Long explanation, technical evidence and secondary rationale move to progressive disclosure without hiding epistemically material facts.

The visual grammar is layered:

1. **L0 foundations** — typography, spacing, radius, elevation and bounded motion tokens.
2. **L1 controls and iconography** — consistent controls and inline Lucide-compatible SVG icons, without a new dependency.
3. **L2 semantic primitives** — attention row, state/owner/boundary, action and progressive detail.
4. **L3 surface grammar** — one local presentation owner per canonical surface.
5. **L4 procedure specialization** — seven procedures preserve their subject-specific semantics without forking the design system.
6. **L5 responsive/motion/accessibility** — semantic order is invariant; geometry may wrap; reduced-motion removes transforms.
7. **L6 E2 falsification** — identity, actionability and capability closure remain blocking.

## Materialized P1 effects

- Home converges to **three** role/scope-derived priority rows at most, with concise hierarchy and one action affordance.
- Process Hub converges from an equal-height card matrix to **one compact row per procedure** in its canonical local owner.
- The later semantic-composition stylesheet no longer corrects Home, Process Hub, Procedure Frame or Proof geometry; those surfaces remain with their existing local owners.
- Procedure headers compress to code + identity + purpose + visible boundary; secondary value/rationale becomes progressive detail.
- ASCII directional arrows are removed from touched canonical owners and replaced by shared inline SVG icons.
- Long descriptive copy uses normal body weight; short labels/titles retain the stronger hierarchy.
- Motion is micro, bounded and disabled for `prefers-reduced-motion`.
- No business route, Store contract, ProcedureAdapter, write authority or human decision authority changes.

## Global DoD

P1 is acceptable only if all of the following are true:

- all 13 canonical surface identities remain represented;
- seven business procedures remain exactly seven and preserve their canonical owners;
- `CAPABILITY-CLOSURE-E2` remains a blocking gate;
- Home/Process Hub/Procedure Frame/Proof presentation is owned locally, not by a new late resolver;
- row/list remains the repeated-record default;
- state/subject/authority/next-action/boundary cannot be removed merely for visual density;
- business truth, write authority and human authority remain unchanged;
- C5 remains a completion gate and UXW-14 remains the final cross-surface falsification unit;
- E3-HUMAN, E3-GOV and E4-DEPLOY remain external.

## Intermediate DoD

- **P1-I1 Foundations:** shared type/density/motion/icon tokens exist in the existing token owner.
- **P1-I2 Local ownership:** Process Hub row geometry is absorbed into 3.2.1 and the old equal-height matrix recipe is absent.
- **P1-I3 Minimal first plane:** Home max three priorities; procedure rationale is progressive while the claim boundary stays visible.
- **P1-I4 Web interaction:** canonical directional affordances use SVG icons; hover/focus transitions are bounded and reduced-motion safe.
- **P1-I5 Falsification:** style and E2 semantic mutation campaigns have zero survivors; canonical CI remains required.

## Local DoD / source constraints

- no new UI framework or icon package;
- no new presentation stylesheet/finalizer;
- no `/api/` calls in the new presentation primitive;
- no CSS palette fork in semantic-composition;
- no `repeat(3,minmax(0,1fr))` or `min-height:226px` Process Hub recipe in the current local owner;
- no surface-specific Home/Process/Proof geometry in the late shared composition layer;
- controls remain keyboard-addressable and responsive layouts do not reorder semantic authority.
