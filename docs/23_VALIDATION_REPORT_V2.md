# Validation report v2

## Gate locali

- repository contract;
- JSON Schema;
- label anti-overclaim;
- invarianti `OutcomeEnvelope`;
- UI wiring manifest;
- dominio e hash-chain;
- quattro tracce ASCII;
- journey HTTP E2E;
- visual attestation;
- Git handshake.

## Esito della foundation

La suite locale è stata eseguita con esito positivo prima della pubblicazione. Gli artefatti runtime e visuali sono generati in CI e non sono versionati.

## Limiti

La beta non include autenticazione enterprise, storage distribuito, scansione malware, alta disponibilità o determinazioni legali automatiche.
