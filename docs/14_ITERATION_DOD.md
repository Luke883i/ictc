# Definition of Done

## Ogni iterazione

- obiettivo umano e non-obiettivi dichiarati;
- owner canonico individuato;
- schema/API aggiornati se necessario;
- label anti-overclaim verificate;
- controlli UI presenti nel wiring manifest;
- scritture con persistenza, readback e receipt;
- test rilevanti e `npm test` verdi;
- documentazione e changelog coerenti;
- limiti e rollback descritti nella PR.

## Cambi UI

Keyboard path, focus, reduced motion, responsive layout e drill-down devono essere verificati.

## Cambi AI

La capsula, le fonti citate, i limiti e l'assenza di write authority devono essere testati.
