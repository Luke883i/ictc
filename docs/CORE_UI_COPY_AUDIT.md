# Core UI copy audit

L'inventario automatico copre HTML, contratto e moduli JavaScript.

## Label primarie

- Cliente
- Profilo
- Monitoraggio
- Incidenti
- Monitora URL
- Aggiungi contenuto
- Segnala
- Rivedi
- Valuta
- Attiva
- Solo lettura

Il copy elimina dalle superfici primarie tassonomie interne e dettagli ripetuti. “Nessuna azione” e “nessun caso” includono sempre il limite epistemico: non significano conformità, completezza o assenza di rischio.
