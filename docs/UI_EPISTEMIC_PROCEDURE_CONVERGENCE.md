# UI / epistemic / procedure convergence — pre-candidate falsification contract

Status: pre-candidate audit authority for the branch. This document does not create business, legal or certification authority.

## Global DoD

The candidate is converged only when one exact GitHub head simultaneously satisfies: (a) the seven canonical business processes remain exactly seven and EP-01 remains cross-cutting; (b) every process has a native standalone completion contract, human checkpoints, evidence and explicit limitation; (c) cross-process draft creation is restricted to declared meaningful edges and preserves source provenance; (d) all epistemic outputs use the shared lattice families/status/basis/relation vocabulary; (e) the lattice offers reversible progressive compression down to raw atom identity/revision/digest; (f) graph interaction is readable, movable and inspectable without semantic writes; (g) canonical controls share one design-system geometry and responsive behavior; (h) semantic, runtime, browser and security gates pass on the exact head. Conditional skips are disclosed separately.

## Point DoD

**1 — UI audit/convergence.** UI-01..05 all pass; browser geometry covers role × viewport and control families rather than screenshot aesthetics alone.

**2 — Standalone ontology.** PR-01..03 pass for all seven processes. “Derived from standards” means the native process contract is cross-referenced to practices already declared in `standard-proof-1-6-contract.json`; it is not a claim that ICTC implements or certifies an external standard.

**3 — Cross-process drafts.** PR-04..05 pass in static, runtime and browser paths. A universal 7×7 matrix is explicitly non-converged because meaning is directional and domain-specific.

**4 — Lattice comprehension/compression.** EP-01..05 pass. Compression is a presentation index: it must be reversible to source atom IDs and projection revision/hash.

**5 — Proto-graph.** GR-01..05 pass. Drag/pan/zoom are presentation state; no graph gesture may mutate domain or semantic persistence.

**6 — Saturation/closure.** VF-01..04 pass, then current semantic/runtime/browser/security suites pass at one exact head.

## Declared standard-practice derivation boundary

Procedure DoD may cite only benchmark/practice families already declared by repository authority (for example accessibility/human-centred design, compliance management, cybersecurity governance, secure development, AI governance). Citations bind a process completion rule to an ICTC practice and evidence path; they do not infer applicability, organisational conformity, legal sufficiency or certification.

## Stop condition

Local DoD → point DoD → global DoD. A green test that merely restates constants is insufficient: source-bound checks, runtime rejection/creation tests, browser interaction tests and independent mutation pressure must all participate. Bounded simulation evidence does not prove universal usability, semantic correctness or absence of unknown defect classes.
