# Arricchimento manuale delle fonti

1. Una persona propone link o file e descrive la rilevanza percepita.
2. ICTC conserva originale e checksum nella SOT locale.
3. Una funzione delimitata propone ecosistema e temi.
4. La fonte resta candidata.
5. Una persona la include o la esclude.
6. La decisione produce evento append-only, readback e receipt.

L'inserimento non prova autorità, applicabilità o completezza.
