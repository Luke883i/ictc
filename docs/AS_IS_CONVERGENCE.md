# AS-IS convergence and entropy guard

`GOV-ASIS-CONVERGENCE-1` is a **derived, authority-zero regression and planning guard**. It does not replace product truth, runtime owners, `v3/gaps.json`, the remediation registry, convergence authority or Git/GitHub.

Its job is to make the current state mechanically hard to misread: consolidate known gaps/findings/slices/external rails into one typed projection, freeze already-established closures as regression baselines, expose documentation/UI entropy, and return exactly one next action or STOP.

## AS-IS lock

A closed debt may be reopened, but never silently. Reopening requires the authoritative source to change state and the new evidence/falsifier to remain attributable. A derived projection cannot close or reopen debt, and current product documentation must not embed a competing live roadmap pointer.

The entropy signature is a digest of the normalized active-debt topology plus current documentation/UI drift and the selected next action. It is a comparison signal, not a maturity or compliance score.

## Strategic mutation tiers

Generic TRAMA remains `1k / 100k / 1M`. This cross-cutting guard adds a **scoped** campaign policy:

- `100k`: bounded multi-owner AS-IS repair;
- `1M`: cross-owner governance/documentation/UI/evidence changes;
- `10M`: AS-IS ratchet, Enterprise Candidate target, authority topology, strategic convergence or cross-surface cognitive-order changes.

Every strategic campaign requires zero unsafe survivors and a deletion oracle. Saturation stops at `M+10k` only when no new root failure family appears. Compression stops at `N+10k` only when no smaller mechanism set preserves all declared semantics. Mutation remains model evidence, never physical proof.

## Enterprise Candidate from iron to human experience

The canonical target remains `v3/trama-enterprise-dod.json`. Its experience lattice is deliberately multi-abstraction: host/supply chain, durable data, identity, runtime/API, AI/information boundary, delivery, operations, administration, compliance work, audit/evidence, end-user cognition and independent external assurance.

Enterprise Candidate therefore means that the same bounded product semantics remain coherent through every layer. It does **not** mean Enterprise Ready and cannot synthesize E3-HUMAN, E3-GOV or E4-DEPLOY.

## Derived falsification topology and safe retirement

AS-IS now derives a **12-node / 15-edge falsification topology** from the existing product, owner, debt, convergence, enterprise-target and legacy authorities. The topology is a projection: it stores no maturity score, writes no product/runtime/convergence state and cannot close E3-HUMAN, E3-GOV or E4-DEPLOY.

Every active debt must resolve to exactly one primary falsification node; an unmapped active debt fails closed as `BLOCKED_DISCOVER_OWNER`. Legacy cleanup reuses `trama-reconcile.legacyCensus()`: a file may be proposed for retirement only when it is already classified `retirement-candidate`, and deletion still requires a dedicated oracle/slice. `blocking-unclassified` is never treated as safe deletion.

The derived operator guidance is deterministic and intentionally low-burden: the human supplies product intent, material acceptance or genuinely external evidence/decision when required. TRAMA derives owner, technical slice, mutation tier, tests, rollback and stop condition from repository state rather than asking a non-technical user to choose them.

The strategic 10M gate invokes the semantic runtime evaluator for every mutation composition. This is real runtime execution of the semantic evaluator, not ten million browser sessions, builds, deployments or external-human trials.

## Cognitive-order contract

Canonical first-plane order is:

`identity -> primary work/decision -> bounded attention/catalog -> context/evidence -> technical detail`.

Home shows product identity, then the next decision, then at most three priority rows. Processi is a seven-row catalogue rather than an equal-salience card wall. Evidenze is decision/evidence first with supporting and technical material progressively disclosed. Procedure surfaces keep primary work before advanced context/reference.

These are executable information-order invariants. They do not claim representative-human comprehension, which remains E3-HUMAN.
