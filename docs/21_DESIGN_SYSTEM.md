# Design system

## Principi

- austero, professionale, minimale;
- nessuna metafora celebrativa o green flag;
- stato espresso con testo prima del colore;
- primo livello iOS-like: conseguenza, owner, tempo, azione;
- livello successivo strutturato: origine, produttore, limiti, receipt;
- movimento riducibile e mai necessario alla comprensione.

## Palette

- canvas `#eef1ed`;
- superficie `#ffffff`;
- testo `#202421`;
- slate operativo `#3f5950`;
- attenzione umana `#8a6436`;
- proposta AI `#625d77`;
- failure `#85525a`.

## Componenti

Radar hero, outcome card, state pill, detail sheet, command palette, assistant drawer, modal di acquisizione, traccia ASCII runtime.
