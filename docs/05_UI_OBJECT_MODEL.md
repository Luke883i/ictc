# Modello oggetti UI

La UI renderizza soltanto `OutcomeEnvelope`.

## Livello 1

Etichetta, statement, stato, owner o prossima azione e tempo.

## Livello 2

Produttore, input, limiti, decisioni disponibili e receipt.

## Livello 3

JSON, hash, identificativi e log tecnici.

Gli oggetti principali sono headline, proof tile, source card, finding card, scout job, control coverage, matter e runtime trace.
