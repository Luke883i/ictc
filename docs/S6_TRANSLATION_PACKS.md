# S6 — TRANSLATION-PACKS

Translation packs are bounded runtime mappings from ICTC practices to external references. They never change ProcessDefinition, human authority, evidence, or epistemic state. Every mapping is `not-assessed`, requires external assessment for any standard-level conclusion, carries a limitation and names its edition.

Initial packs: WCAG 2.2, NIST CSF 2.0 (2024), ISO 37301:2021 with Amendment 1:2024 explicitly acknowledged, and Regulation (EU) 2024/1689 context for AI governance. Mappings intentionally avoid unsupported clause-level precision.
