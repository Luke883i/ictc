# PoC ASCII runtime

Le tracce ASCII sono generate da `buildState().views.traceCards`, la stessa proiezione usata dalla UI.

Tracce disponibili: monitoraggio normativo, fonte manuale, scouting schedulato ed evento/incidente.

Ogni step mostra stato, statement, produttore, input e receipt. Una traccia non può rappresentare come conclusa una fase ancora in attesa di review.
